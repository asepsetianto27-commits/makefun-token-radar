Token Radar ranks 178 pre-token protocols from a sealed DefiLlama snapshot by implied launch value — all 40 on the watchlist plus 138 early finds below the floor — each with a concrete six-step farm plan, in a no-network dashboard. The implied value follows one stated formula from the snapshot's own figures (TVL, seven-day growth, age with no token, chain breadth); live-token protocols are set aside with their market caps. Built by an AI agent for make.fun's “Build the best token launch radar” bounty, $1,325 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
